# Índice das fontes

Este diretório contém as fontes que orientam agentes e implementação. O conteúdo em Markdown é a versão operacional. Os arquivos em `originais/` servem apenas como arquivo histórico.

## Produto

- `produto/plano-de-negocio.md`: contexto completo, módulos, público, modelo de negócio e roadmap.
- `produto/regras-de-negocio.md`: regras RN 001 a RN 035.

## Design

- `design/briefing-marca-ux.md`: sistema visual, interação e responsividade.
- `design/decisoes.md`: itens aprovados e ainda abertos.
- `design/catalogo-artes.md`: finalidade e estado de cada imagem.
- `design/referencias/`: imagens exploratórias.

## Técnica

- `tecnica/arquitetura.md`: stack, topologia, isolamento e marcos.
- `tecnica/decisoes/`: ADRs e decisões técnicas registradas.
- `tecnica/contratos/`: contratos de API quando existirem.

## Pendências

- `pendencias.md`: decisões de produto, design, técnica e processo ainda abertas.

## Uso pelos agentes

Não carregue todos os documentos por padrão. Leia a fonte diretamente ligada à tarefa e consulte as demais apenas quando houver dependência real.
