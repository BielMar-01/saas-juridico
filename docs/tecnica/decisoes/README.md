# Decisões técnicas

Este diretório receberá registros de decisão arquitetural em Markdown.

Padrão de nome: `ADR-0001-titulo-curto.md`.

Cada ADR deve registrar contexto, opções consideradas, decisão, consequências e estado. Nenhuma decisão aberta da arquitetura deve ser tratada como concluída sem um ADR ou atualização explícita da fonte técnica.

- `ADR-0001-url-canonica-e-indexacao-publica.md` — URL canônica, indexação pública e documentos legais preliminares.
